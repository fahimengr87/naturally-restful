# 90-Day Link Building Calendar

Cadence: ~45 minutes/day, 5 days a week. Quality over volume — 5 excellent
pitches/week beats 30 generic ones in 2026.

## Month 1 — Foundation & first wave

- **Week 1:** Deploy the new on-site assets (done: /sleep-statistics, /press,
  schema, robots). Submit statistics hub + Reality Index to Google via GSC.
  Request indexing. Set up Ahrefs free Webmaster Tools + track AI citations
  baseline (run the 3 test queries, log results).
- **Week 2:** Build prospect list #1: 40 health/wellness blogs that cite sleep
  stats. Log in prospect-tracker.csv. Send 5 template #1 emails.
- **Week 3:** Send 5 template #1 emails. Build prospect list #2: 30 pages
  covering glycine/ashwagandha/magnesium without sources (template #2/#3
  targets). Send 5 template #2.
- **Week 4:** Send 5 template #2/#3. First monthly KPI review: referring
  domains, referral traffic, AI citation check. Follow up all week-2/3 sends.

## Month 2 — PR & authority

- **Week 5:** Sign up for Qwoted + Featured + Connectively; set alerts for
  sleep/insomnia/supplement/stress queries. Respond within 15 min of any match.
- **Week 6:** Continue 5 outreach sends (mix #1–#3). Run a broken-link sweep
  on 20 health resource pages; send 5 template #4.
- **Week 7:** Publish Reality Index November edition (trend lines now have 3
  points — "glycine holds / falls" is a story). Pitch the trend angle to 5
  journalists who covered the supplement space (template #2 variant).
- **Week 8:** Monthly KPI review + follow-ups. Guest-post pipeline: check
  guest-post-pitches.md status, refresh 2 pitches if unanswered.

## Month 3 — Compound

- **Week 9–10:** Re-run AI citation queries; for any engine not citing us,
  strengthen llms.txt entries and internal links to the strongest page on
  that topic. Continue 5 sends/week.
- **Week 11:** Analyze which template converts (tracker: status=Link won).
  Double down on the winner; retire the worst.
- **Week 12:** Quarterly review: total new referring domains vs. baseline,
  AI citation presence (3 engines × 3 queries), rankings for "sleep
  statistics". Plan next quarter: one NEW linkable asset (e.g., annual
  "State of Sleep Supplements" report from accumulated Reality Index
  editions — December is perfect timing for "2027 predictions" pitches).

## Standing weekly habits (10 min each)

- Mon: send follow-ups from previous week.
- Wed: 1 Quora answer or Reddit comment (value-first, link only if natural).
- Fri: log new prospects found while reading; update tracker statuses.
